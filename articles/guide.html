記事の足し方、数式と TikZ の図の書き方、GitHub Pages での公開と更新の手順をまとめた、このサイトの取扱説明書。

この記事は Gnomon そのものの取扱説明書です。記事の足し方、数式と図の書き方、GitHub Pages での公開と更新の手順をまとめておきます。

ファイルの構成

サイトは次のファイルでできています。

  • index.html … サイト本体（見た目と仕組み）。記事を足すときは触らない
  • articles/ … 記事のフォルダ。記事1本につき .html を1つ置く
  • articles/list.txt … 公開する記事のファイル名の一覧
  • articles/_template.html … 新しい記事のひな形
  • README.md … リポジトリの説明
  • fig1.tex … TikZ で描いた図の見本
  • pdfs/ … 記事に載せる PDF を置くフォルダ

ページを開くと、index.html が list.txt に書かれた記事を読み込みます。Articles の一覧カードやトップの「RECENT ARTICLES」は、読み込んだ記事から自動で作られるので、一覧を別に書き直す必要はありません。

記事を書く

記事1本は、articles/ の中の .html ファイル1つです。

  1. articles/_template.html をコピーして、名前を変える（例：canonical-ensemble.html）
  2. articles/list.txt にファイル名を1行足す（canonical-ensemble。.html は省略可）
  3. コピーしたファイルの中身を書き換える
<section class="post" data-letter="C"
         data-date="2026-11-20" data-field="stat"
         data-tag="Statistical Mechanics">
  <h1 class="post-title">タイトル</h1>
  <p class="post-abstract">一覧に出る短い説明</p>
  <div class="post-body">
    <p>本文</p>
  </div>
</section>
  • ファイル名 … 記事のアドレス。canonical-ensemble.html なら …/#canonical-ensemble で直接開ける。英小文字・数字・ハイフンだけを使う
  • data-letter … サムネイルと記事見出しで六角形に組まれる文字。省略するとファイル名の頭文字になる
  • data-date … 日付。日付が入っている記事だけが、トップの「RECENT ARTICLES」に新しい順で3件まで出る
  • data-field … 絞り込みボタン用の分野。stat・quant・mech・math・guide のどれか
  • data-tag … 日付の横に出る分野名

ALL ARTICLES には list.txt に書いた順に並びます。行を消すか頭に # を付けると、ファイルは残したまま非公開にできます。

数式を書く

数式は KaTeX で組みます。TeX はかならず HTML の data-tex 属性に書いてください。JavaScript の文字列の中に TeX を書くと、バックスラッシュの扱いで式が壊れやすいので、この方式に統一しています。 

文中の式：<span class="tex-inline" data-tex="E = mc^2"></span>
別行立て：<div class="math-display" data-tex="\int_0^\infty e^{-x}\,dx = 1"></div>

属性の中では、次の文字だけ書き換えが必要です。

  • &（揃える位置）→ &amp;
  • < → \lt、> → \gt
  • " は使わない

たとえば aligned で複数行にそろえる式はこう書きます。長い式はこうして改行しておくと、スマホでも横にはみ出しません。

<div class="math-display" data-tex="\begin{aligned}
  Z(\lambda) &amp;= \int d\Gamma\, e^{-\beta H(\Gamma;\lambda)} \\
  F(\lambda) &amp;= -\beta^{-1} \ln Z(\lambda)
\end{aligned}"></div>

表示はこうなります。

書き間違えた式は、その式だけが赤い点線の枠で原文のまま表示され、ほかの式は止まりません。ページ下の「Typeset with KaTeX · n/n」の2つの数字がそろっていれば、全部の式が正しく組めています。

図を入れる（TikZ）

図は TikZ で描き、公開する前に SVG に変換してから貼ります。ブラウザで TikZ を動かさないので、図のエラーは手元で変換した時点で見つかります。

  1. fig1.tex をまねて fig2.tex を作る（\documentclass[tikz,border=4pt]{standalone}）
  2. PDF にする：pdflatex fig2.tex
  3. SVG にする：pdftocairo -svg fig2.pdf fig2.svg（Poppler に入っているコマンド）
  4. SVG の <svg …>…</svg> の部分を、記事の <figure class="figure-block"> の中に貼る

1ページに図を2枚以上貼るときは、ひとつ注意があります。pdftocairo は文字の形に glyph-0-0 のような名前（id）を付けるので、図どうしで名前がぶつかって、ラベルの文字が別の図のものに化けることがあります。次の短い Python で、名前に図ごとの印を付けてから貼ってください。 

import re, sys

# 使い方: python fixid.py fig2 fig2.svg  → fig2.inline.svg ができる
name, src = sys.argv[1], sys.argv[2]
s = open(src, encoding="utf-8").read()
s = re.sub(r'id="([^"]+)"', rf'id="{name}-\1"', s)
s = re.sub(r'href="#([^"]+)"', rf'href="#{name}-\1"', s)
s = re.sub(r'url\(#([^)]+)\)', rf'url(#{name}-\1)', s)
open(name + ".inline.svg", "w", encoding="utf-8").write(s)

PDF を載せる

授業ノートのスキャンや LaTeX で書いたレポートなど、PDF はそのままアップロードして記事の中で読めるようにできます。スマホのブラウザは PDF をページに埋め込めないことが多いので、Gnomon では PDF.js で1ページずつ画像にして表示しています。

  1. GitHub のリポジトリで「Add file」→「Create new file」を開き、名前の欄に pdfs/x と打って何か1文字書いて保存する（これで pdfs フォルダができる。x はあとで消してよい）
  2. pdfs フォルダを開いて「Add file」→「Upload files」で PDF を上げる。ファイル名は英数字とハイフンにしておくと安全（例：thermo-week3.pdf）
  3. 記事の <section> に data-pdf="pdfs/thermo-week3.pdf" を足す
<section class="post" data-letter="C"
         data-date="2026-11-20" data-field="stat"
         data-tag="Statistical Mechanics"
         data-pdf="pdfs/thermo-week3.pdf">
  <h1 class="post-title">熱力学 第3回のノート</h1>
  <p class="post-abstract">授業ノートの PDF</p>
  <div class="post-body"></div>
</section>

これで記事の本文の下に PDF の1ページ目が見本として出て、タップすると全画面のリーダーで全ページを読めます。一覧のカードには「PDF」の印が付きます。本文の途中に置きたいときは、好きな位置に <div class="pdf-view" data-src="pdfs/thermo-week3.pdf"></div> と書きます。

下は見本です。いっしょに渡した sample.pdf を pdfs/sample.pdf としてアップロードすると、ここに表示されます。まだアップロードしていないときは、手元の PDF を選んで表示を試せます。

注意：GitHub のリポジトリは Public なので、上げた PDF は誰でもダウンロードできます。配布が禁止されている授業資料や教科書のスキャンは上げないでください。1ファイル 25MB を超えるものは、ブラウザからはアップロードできません。

授業ごとに資料を並べる

授業の回ごとに、説明と資料をひとまとめにして並べることもできます。回の見出しをタップすると開いたり閉じたりでき、PDF をタップすると全画面のリーダーで開きます。リーダーには右上に「今のページ / 全ページ」、下に拡大・縮小のボタンがあり、スマホの「戻る」でも閉じられます。 

<div class="materials">
  <details class="unit" open>
    <summary>第1回　ガイダンス（9/15）</summary>
    <div class="unit-body">
<p>この回の説明</p>
<a class="res" href="pdfs/week1-notes.pdf">講義ノート</a>
<a class="res" href="https://example.com">参考リンク</a>
    </div>
  </details>
  <details class="unit">
    <summary>第2回　……</summary>
    ……
  </details>
</div>
  • <details class="unit" open> … 授業1回分。open を付けた回は、最初から開いた状態で表示される
  • <a class="res" href="…"> … 資料1つ。.pdf で終わるものには PDF のアイコンが付いてリーダーで開き、それ以外はリンクのアイコンが付いて別のタブで開く

公開と更新（GitHub Pages）

  1. GitHub のリポジトリ gnomon を開く
  2. articles フォルダを開いて「Add file」→「Upload files」で、書いた記事の .html と list.txt を選んで「Commit changes」を押す（同じ名前のファイルは上書きされる）。PC の VS Code からなら、「ソース管理」でコミットして「変更の同期」を押す
  3. 1〜2分待って https://（ユーザー名）.github.io/gnomon/ を開く。古いままなら再読み込みする

初めて公開するときだけ、「Settings」→「Pages」で Source を「Deploy from a branch」、Branch を main と / (root) にしておきます。Public リポジトリなので、ファイルの中身は誰でも見られる点に注意してください。

公開前のチェック

PC で公開前に見た目を確かめるときは、VS Code の拡張機能「Live Server」を入れて、右下の「Go Live」を押します。index.html をダブルクリックで直接開くと、ブラウザの制限で記事を読み込めません。

  • ページ下の「Typeset with KaTeX · n/n」の2つの数字がそろっている
  • スマホで開いて、長い式や図が横にはみ出していない
  • Articles の絞り込みボタンを押すと、新しい記事が正しい分野に出る
  • #guide のような記事のアドレスで、その記事が直接開ける
  • PDF を載せた記事で、1ページ目の見本が出て、タップすると全画面で全ページ読める
